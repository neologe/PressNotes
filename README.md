# PressNotes

Big, high-contrast notes with a one-tap COPY button. Options menu sets font size and colors.

## Get the APK (no Android Studio needed)
1. Create a new GitHub repo and upload everything in this folder (keep the `.github` folder).
2. Open the repo's **Actions** tab. The "Build APK" run starts automatically (or click *Run workflow*).
3. When it turns green, open the run and download the **PressNotes-apk** artifact. Unzip it.
4. Copy `app-debug.apk` to your phone and open it (allow "install unknown apps" when asked). Needs Android 8+.

## Or build locally
Open the folder in Android Studio and press Run.
